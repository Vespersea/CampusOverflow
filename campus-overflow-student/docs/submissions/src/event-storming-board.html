🔥 Hot Spot(工作坊遗留问题与决议)
H-1 声誉反作弊
小号互刷 → 每人每日被投票正向上限 200,超出截断 + 审计(ADR-009)
H-2 事件幂等
至少一次投递 → 账本/通知唯一键 + processed_event 表(ADR-002/004)
H-3 自问自答
采纳不给分(acceptedDelta = 0),防止刷分
H-4 改投增量
"新效果 − 旧效果"计增量,负向不受每日上限约束
H-5 冻结模型
发起即冻结,采纳结算给胜者,到期/自答退款(ADR-009)
H-6 "一天"界定
UTC 自然日(与全库 UTC 一致),跨日自动重置
H-7 中文搜索
MySQL ngram(ngram_token_size=2),单关键词 ≥2 字符(ADR-005)
H-8 最终一致
发件箱异步投递,数百毫秒延迟,演示与文档需说明
外部系统(黄色,课程不实现)
邮件服务:预留 NotificationCreated 适配点 · OAuth 第三方登录:学号+密码已满足要求,保留扩展点
