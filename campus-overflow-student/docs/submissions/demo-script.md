# 演示录屏脚本(Demo Scripts)

> 用于 Lab 5(30 秒端到端录屏)与 Lab 6(Sprint Review 演示)。
> 录屏工具:Windows 自带 **Xbox Game Bar**(`Win+G` → 捕获)或 OBS Studio;录完用剪映截取到要求时长即可。

## 录屏前置检查(每次录制前 2 分钟)

1. MySQL 与 Redis 已启动(`mysql` 服务 + redis-windows 手动启动);
2. 后端已启动:`cd backend && mvn spring-boot:run`(或 IDE 直接跑 `CampusOverflowApplication`),确认 `http://localhost:8080/actuator/health` 返回 UP;
3. 前端已启动:`cd frontend && npm run dev`,浏览器打开 `http://localhost:5173`;
4. 演示账号就绪:注册一个演示学生账号(或使用 `SPRING_PROFILES=prod,demo` 的演示数据),**记住学号与密码,提前登录一次**避免录屏时输入卡壳;
5. 关闭无关窗口与通知弹窗(录屏区域干净)。

## §1 Lab 5:提问 → 列表 → 详情,30 秒脚本

| 时间 | 画面 | 操作与台词 |
| --- | --- | --- |
| 0–5 s | 首页问题列表 | 打开 `http://localhost:5173/questions`,"这是 CampusOverflow 首页问题列表,按课程与分页浏览。" |
| 5–10 s | 登录 | 点右上角登录,输入演示账号,回车。"登录成功后,顶部显示我的昵称。" |
| 10–22 s | 发布问题页 | 点"提问"进 `/questions/new`,输入标题《高等数学期中复习建议》、选课程、写两行 Markdown 正文、加标签,点提交。"发布一个问题,标题、Markdown 正文、最多 5 个标签。" |
| 22–26 s | 跳转详情页 | 提交后自动跳转到 `/questions/:id` 详情页,"提交成功后自动跳转到问题详情页,这是刚才发布的问题。" |
| 26–30 s | 返回列表 | 回列表页,新问题已出现,"回到列表,新问题已在列表中显示。端到端闭环完成。" |

验收要点:Lab 5 交付物 4 要求"提问 → 列表显示 → 详情查看 端到端跑通",本脚本正好覆盖,总时长 30 秒内。

## §2 Lab 6:Sprint Review 演示脚本(每队 5 分钟)

| 时间 | 环节 | 操作 |
| --- | --- | --- |
| 0:00–0:30 | Sprint 目标回顾(PO) | 一句话目标:"Sprint 3 交付投票、采纳、评论、标签、声誉计算五个核心特性。" |
| 0:30–1:00 | 注册/登录 + 提问 | 演示账号 A 登录 → 发布问题《算法期末考试范围?》 |
| 1:00–1:30 | 回答 | 账号 B(无痕窗口或另一浏览器)登录 → 回答该问题 |
| 1:30–2:00 | **投票** | A 给 B 的回答点赞,B 的声誉 +10;展示改投/撤销(声誉按增量变化) |
| 2:00–2:30 | **采纳** | A 采纳 B 的回答,B 声誉 +15,问题状态变为"已解决";展示 B 的通知中心收到"被采纳"通知 |
| 2:30–3:00 | **评论与标签** | A 在回答下评论并 @B,B 收到 MENTIONED 通知;展示问题标签可点击筛选 |
| 3:00–3:30 | **声誉计算** | 打开 B 的个人声誉档案页:账本流水逐笔解释(+10 投票、+15 采纳);展示徽章(FIRST_ANSWER / FIRST_ACCEPTED);排行榜周榜出现 B |
| 3:30–4:00 | **跨模块验证** | 搜索《算法期末考试》命中刚发布的问题(Discovery 投影);口头说明:Identity 注册事件 → Reputation 开户,Q&A 采纳事件 → 声誉结算 + 徽章 + 通知 + 搜索投影,全部经发件箱最终一致 |
| 4:00–5:00 | 问答环节 | 回答"利益相关者"(其他团队 + 教师)提问;PO 记录反馈纳入 Sprint 4 Backlog |
