# 快速开始

目标：**15 分钟内**把后端、前端、数据库跑起来，并知道“红色测试是正常的”。

## 1. 前置环境

| 依赖 | 版本 | 检查命令 |
| --- | --- | --- |
| JDK | 21 | `java -version` |
| Maven | 3.9+ | `mvn -v` |
| Node.js | 20+（CI 用 20） | `node -v` |
| Docker Desktop | 运行中 | `docker info` |

> 首次 `mvn` 会下载大量依赖，慢是正常的；公司/学校网络慢就配一次镜像。

## 2. 起中间件（MySQL + Redis）

在工程根目录 `campus-overflow-student/` 下执行：

```bash
docker compose -f deploy/docker-compose.yml up -d mysql redis
```

- MySQL：`localhost:3306`，库 `campus_overflow`，账号 `campus / campus_dev_pwd`（root 密码 `root_dev_pwd`）；
- Redis：`localhost:6379`；
- MySQL 已带 `--ngram-token-size=2`，**中文全文检索依赖它**，别换成自建库（见 [常见问题](常见问题与排错)）。

等健康检查变绿：

```bash
docker compose -f deploy/docker-compose.yml ps
```

## 3. 跑测试（第一次是红的，这是设计）

```bash
cd backend
mvn clean test
```

看到一片 `UnsupportedOperationException: TODO(S2)...` 与失败的测试**不是环境问题**——那些 `TODO` 方法就是本学期的需求。详见 [路线图与任务状态](路线图与任务状态)。

跑单个测试类（推荐用这种方式做 TDD）：

```bash
mvn test -pl co-qa/co-qa-domain -Dtest=QuestionTest
```

## 4. 启动后端

```bash
cd backend
mvn spring-boot:run -pl co-bootstrap -Dspring-boot.run.profiles=dev
```

- 端口：`8080`（可用 `SERVER_PORT` 覆盖）
- 健康检查：<http://localhost:8080/actuator/health>
- 接口文档：<http://localhost:8080/swagger-ui.html>

> 不要加 `demo` profile：演示数据依赖完整业务实现，未实现时启动会报错。

## 5. 启动前端

```bash
cd frontend
npm install
npm run dev          # http://localhost:5173
```

前端通过 Vite 代理调用 `8080` 的后端；登录用的是 **Cookie 会话 + CSRF**，所以浏览器里要允许该站点的 Cookie。

## 6. 一键起完整环境（可选）

```bash
# 应用三件套（mysql + redis + backend + nginx）
docker compose -f deploy/docker-compose.yml up -d --build

# 再叠加监控（Prometheus + Grafana）
docker compose -f deploy/docker-compose.yml --profile observability up -d --build
```

| 服务 | 地址 |
| --- | --- |
| 前端（Nginx） | <http://localhost> |
| 后端 | <http://localhost:8080> |
| Prometheus | <http://localhost:9090>（observability） |
| Grafana | <http://localhost:3000>（observability） |

## 7. 自检清单

| 检查项 | 命令 | 期望 |
| --- | --- | --- |
| 中间件 | `docker compose -f deploy/docker-compose.yml ps` | mysql / redis 为 healthy |
| 后端起得来 | `curl http://localhost:8080/actuator/health` | `{"status":"UP"}` |
| 接口文档 | 浏览器打开 `/swagger-ui.html` | 能看到分组接口 |
| 前端起得来 | `npm run dev` | 5173 打开是登录页 |
| 代码规范 | `cd frontend && npm run lint` | 无 error |
| 类型检查 | `npm run typecheck` | 无输出 |

## 8. Windows 下的几个提醒

- 路径里有中文没问题，但**别在含空格的路径**里跑 `mvn`（某些插件会挂）；本仓库建议放在 `D:\...` 这类短路径。
- PowerShell 里 `-D` 后面的参数要用引号包住整段：`mvn spring-boot:run -pl co-bootstrap "-Dspring-boot.run.profiles=dev"`。
- Docker Desktop 没启动时，`mvn verify` 的集成测试会失败（Testcontainers 拉不到 Docker），这不是代码问题。
- 控制台出现中文乱码是终端编码问题，与代码无关；确认 `-Dfile.encoding=UTF-8` 即可。

## 9. 环境变量（compose 用）

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `MYSQL_ROOT_PASSWORD` | `root_dev_pwd` | MySQL root |
| `DB_PASSWORD` | `campus_dev_pwd` | 应用账号密码 |
| `SPRING_PROFILES` | `prod,demo` | 容器内激活的 profile |
| `CO_FIELD_KEY` | 内置测试密钥 | 字段级加密密钥，**生产必须换** |
| `COOKIE_SECURE` | `false` | 走 HTTPS 时改 `true` |
